# C5Online

A beginner Java programming project containing simple examples and exercises while learning the fundamentals of Java.

## 📚 Topics Covered

The project currently includes examples covering:

- Basic Java program structure
- Data types
- Operators
- Swapping two numbers
- Basic programming practice

## 📁 Project Structure

C5Online/
└── src/
    └── day1/
        ├── DataTypes.java
        ├── FirstJavaProgram.java
        ├── Operators.java
        └── SwappingTwoNumbers.java
        
🛠️ Technologies

Java

Git
GitHub

▶️ How to Run

Clone the repository.
Open the project in IntelliJ IDEA.
Open any Java file inside src/day1/.
Run the file using IntelliJ's Run button.
